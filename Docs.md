This document is the master technical reference manual for the ZeroDaily serving backend (`api.zerodaily.in`) and the automated breaking news notification worker.

## 1. System Architecture & Component Roles

ZeroDaily operates as a high-throughput, low-latency news delivery platform with a decoupled producer-consumer model:

## 2. Database Schema & Global Secondary Indexes (GSIs)

All primary data lives in **Amazon DynamoDB** in `us-east-1` with on-demand capacity (`PAY_PER_REQUEST`).

### Table: `zerodaily-articles`

#### Primary Key
- **Partition Key (`HASH`):** `id` (`String` - Canonical source article URL)

#### Core Attributes
| Attribute | Type | Description |
| :--- | :--- | :--- |
| `id` | `String` | Canonical source URL (e.g. `https://thehackernews.com/2026/09/...`). |
| `category` | `String` | One of `cybersec`, `ai`, `programming`, `robotics`, `defense_aerospace`, `hardware`, `finance`. |
| `published_at` | `String` | ISO-8601 UTC timestamp (e.g. `2026-09-16T12:00:00Z`). Used as the sort key. |
| `feed_bucket` | `String` | Fixed value `"ALL"`. Used to partition the cross-category global feed. |
| `title` | `String` | Original unaltered source headline. |
| `heading` | `String` | Satirically roasted headline generated by Bedrock DeepSeek. |
| `shortSummary` | `String` | Condensed, witty bullet or paragraph summary. |
| `fullSummary` | `String` | Complete multi-paragraph roasted breakdown. |
| `image_url` | `String` | Cloudflare CDN URL: `https://media.zerodaily.in/images/{category}/{hash}.webp`. |
| `link` | `String` | Link to original article source. |
| `is_breaking` | `Boolean` | `True` ONLY when the article qualifies for breaking news push alerts. |
| `push_punchline`| `String` | High-impact alert copy (max 50 characters) sent via FCM. |
| `created_at` | `String` | ISO-8601 UTC timestamp of ingestion. |

#### Global Secondary Indexes (GSIs)

1. **`GlobalFeedIndex`** (Cross-Category Unified Feed)
   - **Partition Key (`HASH`):** `feed_bucket` (`String`, always `"ALL"`)
   - **Sort Key (`RANGE`):** `published_at` (`String`)
   - **Projection:** `ALL`
   - **Query Pattern:**
     ```python
     KeyConditionExpression = Key("feed_bucket").eq("ALL") & Key("published_at").lt(cursor)
     ScanIndexForward = False  # Newest first
     ```

2. **`CategoryIndex`** (Category-Specific Feed)
   - **Partition Key (`HASH`):** `category` (`String`)
   - **Sort Key (`RANGE`):** `published_at` (`String`)
   - **Projection:** `ALL`
   - **Query Pattern:**
     ```python
     KeyConditionExpression = Key("category").eq(category) & Key("published_at").lt(cursor)
     ScanIndexForward = False  # Newest first
     ```

### Table: `zerodaily-users`
User account credentials, reading telemetry, and dynamic category affinity weights.

#### Primary Key
- **Partition Key (`HASH`):** `user_id` (`String` - `usr_...`, `guest_...`, `fb_...`)

#### Global Secondary Indexes (GSIs)
- **`EmailIndex`**: Partition Key `email` (`String`), Projection `ALL`. Enables $O(1)$ email lookup during sign-in and duplicate account checking.

#### Attributes & Personalized Feed Schema
- `user_id`: Unique identifier.
- `email`: Normalized lowercase email address.
- `password_hash`: Bcrypt hash (rounds: 12) for email authentication.
- `display_name`: User alias.
- `is_anonymous`: Boolean flag distinguish guest vs permanent account.
- `topic_preferences`: Category toggles for notification & feed filtering.
- `algo_weights`: Category affinity multipliers ($0.1 \le w \le 3.0$) adjusted on dwell, bookmark, share, skip.
- `bookmarked_articles`: List of saved canonical article IDs.
- `reading_history`: Sliding window of last 50 read events.
- `reading_count`: Total stories read count.

## 3. Cloudflare Edge Caching Strategy

To deliver a **sub-20ms mobile experience** while keeping AWS Lambda execution costs near zero, edge caching rules are enforced via HTTP `Cache-Control` response headers:

| Route | `Cache-Control` Header | Edge TTL | Browser TTL | Stale While Revalidate | Rationale |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `/api/v1/feed*` | `public, max-age=60, s-maxage=300, stale-while-revalidate=600` | 5 min | 1 min | 10 min | Serves cached feed instantly while refreshing in background. |
| `/api/v1/articles/*` | `public, max-age=3600` | 1 hour | 1 hour | N/A | Roasted stories are immutable once generated. |
| `/api/v1/categories` | `public, max-age=86400` | 24 hours | 24 hours | N/A | Static category taxonomy. |
| `/health` | `no-store` | 0 | 0 | None | Accurate runtime health diagnostics. |
| `media.zerodaily.in/*` | `public, max-age=2592000` | 30 days | 7 days | N/A | WebP assets are immutable (hash-addressed). |

## 4. API Endpoints Specification

Base URL: `https://api.zerodaily.in`

### 1. Global Chronological Feed
Returns the unified feed across all categories, ordered newest first.

- **Path:** `GET /api/v1/feed`
- **Query Parameters:**
  - `limit` (`int`, optional, default: `20`, min: `1`, max: `50`): Maximum items to return.
  - `cursor` (`string`, optional): ISO-8601 UTC timestamp for cursor pagination (from previous `pagination.next_cursor`).
- **Response `200 OK`:**
```json

  "data": [
```

## 5. Event-Driven Notification Engine

### DynamoDB Stream Trigger & Filtering
The notification worker ([`workers/stream_handler.py`](file:///D:/zerodaily/workers/stream_handler.py)) is triggered via DynamoDB Streams on table `zerodaily-articles` with `StreamViewType: NEW_IMAGE`.

#### Qualification Criteria:
1. `record["eventName"] == "INSERT"` (ignores `MODIFY` and `REMOVE`).
2. `record["dynamodb"]["NewImage"]["is_breaking"]["BOOL"] == True`.
3. `record["dynamodb"]["NewImage"]["id"]["S"]` does not start with `"NOTIF_"`.

### Atomic 30-Minute Cooldown & Rate Limiting
To prevent notification storms if multiple related stories break at once:
- Managed by [`app/services/cooldown.py`](file:///D:/zerodaily/app/services/cooldown.py).
- Uses DynamoDB conditional write:
  ```python
  table.put_item(
      Item={
          "id": f"NOTIF_COOLDOWN#{category}",
          "category": category,
          "last_sent_at": now_iso,
          "last_article_id": article_id,
          "ttl": expiry_epoch  # current_time + 1800
      },
      ConditionExpression="attribute_not_exists(id) OR #ttl_field <= :now_epoch",
      ExpressionAttributeNames={"#ttl_field": "ttl"},
      ExpressionAttributeValues={":now_epoch": current_epoch}
  )
  ```
- If a push was sent within the last 30 minutes, `ConditionalCheckFailedException` is raised and the notification is suppressed.
- Auto-deletes via DynamoDB Native TTL. Zero Redis or external state required.

### FCM HTTP v1 Dispatch Protocol
Managed by [`app/services/fcm_client.py`](file:///D:/zerodaily/app/services/fcm_client.py):
- Authenticates using Google Service Account credentials (from `.env` or AWS Secrets Manager).
- Obtains OAuth2 Bearer token with scope `https://www.googleapis.com/auth/firebase.messaging`.
- Dispatches to:
  1. Category Topic: `topic_{category}` (e.g. `topic_cybersec`, `topic_ai`, `topic_finance`).
  2. Catch-All Topic: `topic_breaking_all` (for users wanting all breaking alerts).

## 6. Mobile Inshorts Swiper Algorithm

To achieve a 0-spinner swiper experience on mobile (Flutter / React Native / Native):

1. **Cold Boot (0ms UI Render):**
   - App loads the last 20 cached cards directly from local disk (SQLite / Hive / Room / CoreData).
   - Swiper renders immediately without waiting for any network response.
2. **Background Sync:**
   - App fires non-blocking `GET /api/v1/feed?limit=20`.
   - Compares top item `published_at` against local top item.
   - If newer items exist, silently prepends them to the local store.
3. **Prefetch Threshold (`N - 8`):**
   - When the user swipes to card `N - 8` (card 12 of a 20-card batch):
     ```http
     GET /api/v1/feed?limit=20&cursor={published_at_of_card_20}
     ```
   - App appends the next 20 items to local storage.
   - Concurrently pre-downloads the 20 WebP `image_url` assets into device disk cache.
   - Result: Swiping is always instantaneous.

## 7. Production Deployment Guide

### A. AWS Lambda Deployment (Serving API)
1. **Container or ZIP Packaging**:
   FastAPI + Mangum can be packaged as a Docker container image or ZIP bundle.
2. **Lambda Configuration**:
   - **Runtime:** Python 3.11 or Python 3.12 (or container).
   - **Handler:** `app.main.handler`
   - **Memory:** 512 MB (FastAPI response takes ~15–30ms).
   - **Timeout:** 10 seconds.
3. **Enable Lambda Function URL** (or API Gateway HTTP API):
   - Auth Type: `NONE` (public API behind Cloudflare).
   - CORS: Allow all or restrict to `zerodaily.in`.

### B. AWS Lambda Deployment (Stream Notification Worker)
1. **Lambda Configuration**:
   - **Handler:** `workers.stream_handler.lambda_handler`
   - **Memory:** 256 MB.
   - **Timeout:** 30 seconds.
2. **DynamoDB Stream Trigger**:
   - **Table:** `zerodaily-articles`
   - **Stream ARN:** `arn:aws:dynamodb:us-east-1:339087217625:table/zerodaily-articles/stream/2026-09-16T09:39:09.468`
   - **Batch size:** 10
   - **Starting position:** `LATEST`
   - **StreamViewType:** `NEW_IMAGE`
   - **CLI Command:**
     ```bash
     aws lambda create-event-source-mapping \
       --function-name zerodaily-notification-worker \
       --event-source-arn arn:aws:dynamodb:us-east-1:339087217625:table/zerodaily-articles/stream/2026-09-16T09:39:09.468 \
       --batch-size 10 \
       --starting-position LATEST
     ```
